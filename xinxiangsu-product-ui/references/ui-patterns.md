# 页面模式库

8 类模式覆盖产品界面 90% 的场景。**先选模式，再填内容。**

├──────────────────────────────┤
│ 本周热门                查看全部 →│
│ ┌──────────────────────────┐ │
│ │ ┌────────┐               │ │
│ │ │ 封面图  │ 青野湖营地      │ │  ← 卡片 18圆角
│ │ │ (渐变)  │ ★4.9 · 2.3km   │ │
│ │ └────────┘ ¥128/晚  [可订] │ │  ← 价格 用 --font-num
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ …                        │ │

│  ◉发现   ♡收藏   ▤订单   ◯我的 │  ← tabbar，active 主色

```

**要点**
- 封面图位用 CSS 渐变 + 一个 SVG 场景剪影，**不要留灰色占位块**

- 库存状态用徽章（`可订` 绿 / `仅剩3间` 橙 / `已满` 灰）
- 至少要 4 条真实数据（真实营地名、真实距离、真实价格）

**要点**
- `订单数` / `营收` 数字列**右对齐** + 等宽数字 + 点列头排序

- 操作列固定右侧，内容超宽时横向滚动而操作列不动

│ └────────────────────────┘└──────────────────┘│
├ 排行 ─────────────────────────────────────────┤
│ ┌ 营地 TOP5（条形排行，条形宽度=占比，主色填充）┐│
│ │ 青野湖营地 ████████████████ 1,286          ││

```

**要点**
- 图表用**手写 SVG**：折线 `polyline` + `stroke-linejoin:round`；环形用 `stroke-dasharray`；柱状用 `<rect rx="3">`
- 折线图要有：淡主色面积填充（`linearGradient` 到透明）、数据点 hover 显示 tooltip、坐标轴文字 11px 弱色
- KPI 变化值：涨 `#F5222D` + `↑`，跌 `#22C55E` + `↓`，**不要用箭头方向反过来**
- 每张卡片右上角一个「…」更多菜单

## P7 · 空状态 / 加载 / 错误

| 状态 | 结构 |
|---|---|
| 空 | 居中 SVG 线稿插画（120×120，主色 20% 描边）+ 标题 16-600 + 一句说明 13-次色 + 主按钮 |
| 加载 | 骨架屏（`#EDEFF3` 圆角块 + `shimmer` 扫光动画），**不要用转圈铺满屏** |
| 错误 | 插画 + 错误原因 + 两个按钮（重试主色 / 联系客服文字） |

骨架屏 shimmer：
```css
@keyframes shimmer { 0%{background-position:-200% 0} 100%{background-position:200% 0} }
.sk { background:linear-gradient(90deg,#EDEFF3 25%,#F7F8FA 37%,#EDEFF3 63%);
      background-size:200% 100%; animation:shimmer 1.4s linear infinite; border-radius:8px }
```
