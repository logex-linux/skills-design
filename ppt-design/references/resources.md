## Selection method

1. **Keyword design** — 140 English queries covering slide frameworks, PPTX libraries, themes, AI generation, and conversion.
2. **Harvest** — GitHub search API across all queries, producing 9,390 unique repositories.
3. **Filter** — a relevance scorer required the repo's name or description to state a slide/presentation purpose, with a blocklist removing carousel/slider libraries, generic awesome lists, and unrelated repos that matched 'slide' by accident. Stars ranked the survivors, with per-category quotas.
4. **Analyze** — three parallel readers pulled actual READMEs and theme sources, extracting verbatim CSS, tokens, palettes, and design rules into the reference files.
