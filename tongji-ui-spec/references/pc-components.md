# PC 端常用组件完整规格

对应规范第 2 章（PC 端用户交互规范细则）。标注 `*` 为必须遵循条款。

## 2.5.1 按钮 Button

**尺寸**：至少分大、中、小三档

| 档位 | 高度 |
|---|---|
| 大按钮 | 72px |
| 默认（中） | 48px |
| 小按钮 | 32px |

**其他规格**：

- 圆角统一 **9.6px**
- 最小宽度 **80px**；最大宽度由文本宽度决定——文本宽度超出 80px 后，按钮宽度 = 文本宽度 + 16×2px 内边距
- 按钮文字与左右边框间距 **16px**
- 四种形态：**默认态、悬停态、点击态、灰态**

**交互规则**：

- a) 按钮颜色及交互逻辑符合配色规范 `*`
- b) 悬停态：默认态颜色值的**饱和度降低 15%**
- c) 点击态：默认态颜色**饱和度提高 15%**
- d) 统一灰态：**不透明度 40%**

## 2.5.2 输入框 Input

**适用场景**：信息输入、信息采集、搜索。

**基本要求**：

- a) 明确区分默认状态、输入状态、禁用状态
- b) 输入状态时光标聚焦在输入框上
- c) 输入框**右侧应设清空按钮**，点击重置输入内容
- d) 输入框宽度固定，不随文字多少改变；高度按需设置为 **40px / 32px / 24px**
- e) 输入框**居左对齐，标题居右对齐**
- f) 数字输入框宜设置增减数值按钮，点击实现数值增减

## 2.5.3 单选框 / 复选框 Radio / Checkbox

**适用场景**：选项不多时的单项选择。复选框样式须与单选框保持一致，避免用户理解困惑。

**要求**：分为默认态、选中态、灰态，根据系统配色要求分别标识。

## 2.5.4 选择器 Select

**适用场景**：选项过多时的下拉选择，适用于广泛的基础单选（复选）。

**要求**：

- 样式以输入框为基础；可按需配置搜索框
- 备选项**超过 10 项时，宜使用搜索框**提供搜索功能 `*`
- 三种状态：默认态、下拉态、灰态；配色、字体与系统规则一致
- 提供部分选项不可用、可清空至初始状态的选项
- 建议尺寸 **240×32px** 和 **360×32px** 两种，其余尺寸按实际场景决定

## 2.5.5 树形组件 Tree

**适用场景**：体现清晰的层级结构，提供层级展开/折叠，常见于左侧导航栏、分级菜单选择。

**要求**：内容较多时，宜在树形组件上方设置输入框，通过关键字过滤树节点。

## 2.5.6 表格 Table

**适用场景**：展示多条结构类似的数据，一般与筛选条件块同时使用。表格数据块可由标题、快捷查询框、操作按钮、数据表格组成，一般应提供排序、对比等常用操作。

**要求**：

- a) 同一列文本数据长短不一致的应**居左**展示（如地址）`*`
- b) 同一列数据长短基本一致的应**居中**展示（如姓名、性别）`*`
- c) 数据较多时可拖动滑块自定义列宽 `*`
- d) 滑动横向滚动条时**冻结重要字段** `*`
- e) 行高建议 **40px**；列宽根据列内容宽度及显示设备宽度决定，可随设备宽度自动缩放，最小支持宽度 **1200px**

## 2.5.7 分页 Pagination `*`

**适用场景**：数据量较大时，将数据分成固定大小的页面展示；常与表格组合。

**要求**：

- a) 处于第一页时，隐藏或禁用"上一页"按钮
- b) 处于最后一页时，隐藏或禁用"下一页"按钮
- c) 用户可自定义选择每页显示的数据行数
- d) 用户可通过快速跳页翻页
- e) 显示总页数
- f) 总页数 ≤5 时，应显示所有页码
- g) 选中态显示方式符合系统总体要求

## 2.5.8 面包屑 Breadcrumb

**适用场景**：显示当前页面路径，定位当前位置，提供返回上级页面操作。

**要求**：

- a) 按默认态、选中态、悬停态分别设置
- b) 记录当前页面父子关系，可点击父关系快速跳转到父页面

## 2.5.9 滚动条 Scrollbar `*`

**适用场景**：信息量较大、屏幕无法完全显示、又因信息完整性必须全部显示在一个页面时。

**要求**：通过操作滚动条上的滑块，显示默认情况下无法显示的信息。

## 2.5.10 弹窗 MessageBox

**适用场景**：提示操作状态、反馈关键节点、呈现业务数据等。弹窗时阻断用户此前操作。

**要求**：

- a) 应展现在当前页面的**正中间**位置 `*`
- b) 操作类弹窗图标配色符合系统总体要求 `*`
- c) 操作类弹窗统一固定尺寸，如 **504×176px**；其余弹窗宽度可为 600px / 1000px / 1200px，最小高度 320px，最大高度 600px，高度按实际内容定
- d) 一般**确认按钮在右，取消/返回按钮在左** `*`
- e) 弹窗内加载的数据表等内容遵循相应模块要求

## 2.5.11 消息提示 Message

**适用场景**：主动操作后的反馈提示（成功/失败状态、失败原因等），一般无需用户交互；悬浮出现在页面角落，可自定义屏幕四角任意一角；数秒后自动消失，也可添加关闭按钮手动消失；带图标，显示"成功、警告、消息、错误"类系统消息。

**要求**：消息提示应在页面停留 **3 秒**后消失，整个过程不影响用户当前操作。

## 2.5.12 加载器 Loading `*`

**适用场景**：体现数据加载过程和页面跳转过程。

**要求**：

- a) 尺寸可设置 **18px / 36px / 64px** 等
- b) 使用加载器时应做蒙版处理：蒙版背景色 `#FFFFFF`，不透明度 **70%**

## 2.5.13 穿梭框 Transfer

**适用场景**：两个表格间的数据穿梭，如数据筛选、添加、删除。

**要求**：

- 勾选头部复选框 → 同侧数据项全部选中；取消勾选 → 同侧数据全部未选中
- 点击按钮穿梭时，已勾选栏目移动到另一侧穿梭框
- 一侧数据条数为 0 时，穿梭到本侧的按钮为禁用状态

## 2.5.14 标记 Badge `*`

**适用场景**：在按钮、图标旁设置标记，体现数字或状态；常用于新消息提醒、申办业务最新状态提示。

**要求**：

- 标记应放置于组件**右上角**
- 标记上宜标记数字，用于提示未读信息条数

## 2.5.15 进度条 Progress

**适用场景**：动态展示操作进度，常用于文件上传、批量操作等耗时较长操作。

**要求**：可包含线性进度条和环形进度条等。

## 2.5.16 图表 Chart

**适用场景**：直观展示统计信息或数据间关联关系。

**要求**：

- 数据与柱状图、环形图、进度条结合展示，宜用于周期性、对比性、不同类型的数据比例说明，突出一组重要数据
- 推荐使用 **ECharts**（https://echarts.apache.org/zh/index.html）等开源图表库的**默认风格组件**，与系统整体配色和文字形式保持一致
