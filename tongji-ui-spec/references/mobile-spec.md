# 移动端用户交互规范完整规格

对应规范第 3 章。适用范围：挂载于**移动门户微信小程序或企业微信的 H5 应用**，以及个别单位自建的小程序。标注 `*` 为必须遵循条款。

## 3.1 配色 Color

设计原则与 PC 端一致：根据应用用户主体（教师/学生）及功能目标确定风格；总体清新、避免信息过多；系统内部统一主色/辅色与成功/警告/提醒/危险色；**总色调不宜超过 3 种**。

色彩规范与 PC 端完全相同：

- **主色 A `#083DA6`**（常规）/ **主色 B `#CC3300`**（庆祝纪念，A/B 不同时使用）
- **辅助色 5 色**：`#FF9900` 橙 / `#30F090` 绿 / `#A80AF2` 紫 / `#E8316E` 粉 / `#0ECAF0` 青
- **中性色 10 级**：`#000000` → `#F7F7F7`（完整色阶见 `tokens/tongji-tokens.css`），作背景避免中等灰度
- **系统通知**：Success `#07F757` / Warning `#FAE900` / Information `#002EE7` / Error `#DB0000`
- 文本颜色 `#000000` / `#FFFFFF`，确保与背景对比充分

## 3.2 文字 Typography

字体家族与 PC 端相同（微软雅黑/Segoe UI、苹方/Helvetica Neue、iOS San Francisco、Android Roboto），全局一致。

**字号**：

| 用途 | 字号 |
|---|---|
| 标题 | 16 / 18 / 20 / 24 / 32px |
| 按钮文字 | 12 / 16 / 20px |
| 正文 | 12 / 16 / 20px |
| 提示信息 | 12px |
| 标签 | 12px |

- 行距一般为 **1.5 倍**
- 字号可根据实际需求设置阶梯

## 3.3 界面布局

H5 应用界面分**头部区域、内容区域、底部区域**：

- 头部和内容区域按实际需求制定，在不同屏幕保持适配
- **底部标签栏**：用于不同子任务切换，位于界面底部，**个数不超过 5 个**，高度一般 **32px**

## 3.5 常用组件

### 3.5.1 卡片 Card

用于将同一主题功能、组件或信息做集中展示。页面布局中应充分利用卡片实现不同表达目的，使用户快速识别关键信息。

### 3.5.2 按钮 Button

- 至少分大、中、小三档：默认中等 **48px**，小按钮 **32px**，大按钮 **62px**
- 宽度按需设置通栏按钮或固定宽度（如 120px）
- 圆角统一 **9.6px**
- 配色符合 3.1.2，一般情况下采用主色 A `#083DA6` `*`

### 3.5.3 图标按钮 Icon Button

**适用场景**：设置了图标的按钮。校园场景中每个挂载于移动门户/企业微信的 H5 应用都通过图标按钮访问，各类功能也常用图标+文字组合按钮访问，因此应严格规范图标与文字的对应使用。

**要求**：

- a) 图标配色符合 3.1.2，一般情况下采用主色 A `#083DA6` `*`
- b) 图标尽可能简洁大方，含义与应用功能相符
- c) 图标视觉尺寸恰当，长宽比尽量保持 **1:1**（如 36×36px），上下或左右方向至少其中之一的尺寸在满格尺寸的 **80%** 左右
- d) 图标素材可从第三方开放素材库或学校素材库选取
- e) 同一个应用在不同平台中的图标按钮保持一致 `*`

### 3.5.4 输入框 Input

**适用场景**：信息输入、信息采集、搜索。

**要求**：

- a) 高度约 **80–100px**
- b) 输入框标题左对齐，尽量不换行
- c) 必填内容有明确标识
- d) 输入信息后，输入框内右侧应配置清空按钮
- e) 输入框内提示文字使用**中等灰色**配色
- f) 输入框外必要提示文字使用小于正文文字的字号，配色可使用 `#DB0000`

### 3.5.5 标记 Badge

**适用场景**：在按钮、图标旁设置标记，体现数字或状态；常用于新消息提醒、待办任务数提醒、任务状态提示。

**要求**：

- a) 标记颜色符合配色规范 `*`
- b) 标记应放置于组件四角之一，**提醒类放于右上角**
- c) 标记上宜设置数字，用于提示未读信息条数

### 3.5.6 弹窗 MessageBox

**适用场景**：提示操作状态、反馈流程关键节点、确认关键信息等；内容弹窗包含文字标题、按钮等组件。

**要求**：

- a) 弹窗宽度宜为**手机屏幕宽度的 80%**，应提供关闭操作
- b) 弹窗信息宜分为标题区与内容区，文字按 3.2 要求
- c) 按钮按 3.5.2 要求，采用适合弹窗大小的按钮，一般为小按钮
- d) 一般情况下，**确认按钮居右侧，取消按钮居左侧**
