# 合规检查清单（必须遵循条款）

规范正文中标注 `*` 的条款为**必须遵循**。用于设计走查、代码评审、上线前自查。检查项后标注了规范章节来源。

## A. 通用（第 1 章，所有端适用）

- [ ] 页面遵循上下或左右布局，界面简单直白
- [ ] 布局满足四原则：对比 / 重复 / 对齐 / 亲密性
- [ ] 首页之外的页面保持"首页"按钮常驻，并有访问下级目录的引导
- [ ] 页面适配规则定义清晰，兼容主流浏览器，无页面变形、功能组件缺失、文字错行错位
- [ ] PC 端页面基本兼容主流移动浏览器
- [ ] 图片、附件、视频有效可用，名称直观准确；格式采用 JPG / PNG / OFD / PDF / MP4 等主流格式
- [ ] 移动端不使用弹出窗、漂浮窗口（确需使用时：不多个窗口、提供关闭按钮）
- [ ] 移动端支持通用移动终端操作系统

## B. 色彩

- [ ] 主色 A 与主色 B **不同时使用**（B 仅用于庆祝/纪念场景）
- [ ] 总色调不超过 3 种
- [ ] 中性色作为背景时未使用中等灰度色值
- [ ] 文字颜色为黑或白（或从中性色/辅助色选取且对比充分）
- [ ] 按钮颜色及交互逻辑符合配色规范（2.1.2 `*`）

## C. PC 端组件

- [ ] 选择器：备选项超过 10 项时提供搜索框（2.5.4 `*`）
- [ ] 表格：可变长文本列居左、等长列居中（2.5.6 `*`）
- [ ] 表格：数据较多时可拖动滑块自定义列宽（2.5.6 `*`）
- [ ] 表格：滑动横向滚动条时冻结重要字段（2.5.6 `*`）
- [ ] 分页：首页禁用"上一页"、末页禁用"下一页"，总页数 ≤5 显示全部页码（2.5.7 `*`）
- [ ] 滚动条：信息量大且须整页显示时使用滚动条组件（2.5.9 `*`）
- [ ] 弹窗：展现于页面正中间（2.5.10 `*`）
- [ ] 弹窗：操作类弹窗图标配色符合系统总体要求（2.5.10 `*`）
- [ ] 弹窗：确认按钮在右、取消/返回按钮在左（2.5.10 `*`）
- [ ] 加载器：使用蒙版处理，背景 `#FFFFFF`、不透明度 70%（2.5.12 `*`）
- [ ] 标记：置于组件右上角，宜带未读数字（2.5.14 `*`）

## D. 移动端组件

- [ ] 按钮：一般情况下采用主色 A `#083DA6`（3.5.2 `*`）
- [ ] 图标按钮：图标采用主色 A `#083DA6`（3.5.3 `*`）
- [ ] 图标按钮：同一应用在不同平台中保持一致（3.5.3 `*`）
- [ ] 标记：颜色符合配色规范，提醒类置于右上角（3.5.5 `*`）

## E. 大屏端（第 1.2.1 l 条）

- [ ] 设计前已了解展示设备配置：设备类型、尺寸、分辨率、显卡、声卡、内存、网速、操作系统、浏览器
- [ ] 大屏应用已在实际运行机器上验证正常显示

---

**使用方式**：设计/开发完成后逐项核对；评审时按章节引用条款号（如"违反 2.5.10 d"）。
