# 同济大学信息系统 UI 设计风格规范（Tongji UI Style）

蒸馏自《同济大学信息系统用户交互规范（试运行版 20240628）》，18 页，覆盖 **PC 端**、**移动端**、**大屏幕端**三部分。本 skill 提供可直接落地的设计令牌与组件规格。

> **本 skill 只保留设计风格部分**（色彩 / 字体 / 布局 / 组件）。规范原文中的校徽 VI、系统标识等**品牌强制条款已按需求剔除**，不纳入本 skill。
> **条款效力**：规范正文中标注 `*` 的条款为**必须遵循**，其余为建议参考。全文必循条款清单见 [audit-checklist.md](references/audit-checklist.md)。
> **适用范围**：校内所有信息系统。各系统可在本规范下制定自身细节规范，但不得违背本规范。

## 何时使用本 Skill

- 为同济大学校内系统（一网通办、智慧校园各工程、弘文/明德/矢之/求索/力行之星等）设计或开发界面
- 生成 HTML / React / Vue / 小程序页面，需要符合同济视觉规范
- 评审、走查现有系统 UI 是否合规
- 用户提到"同济风格""Tongji UI""一网通办""智慧校园""#083DA6""按学校规范做"

**不适用**：非同济项目（除非用户明确要求参照本风格）。

## 快速开始

1. 拷贝设计令牌到项目：`tokens/tongji-tokens.css`（CSS 变量）或 `tokens/tongji-tokens.json`（JSON / Tailwind / Figma Tokens 可消费）
2. 按下方"色彩 / 字体 / 布局"落地页面骨架
3. 组件规格查 [references/pc-components.md](references/pc-components.md)（PC）与 [references/mobile-spec.md](references/mobile-spec.md)（移动端）
4. 交付前对照 [references/audit-checklist.md](references/audit-checklist.md) 逐项检查 `*` 条款

## 1. 设计原则（通用）

**布局四原则**（让用户快速识别、减少记忆负担，页面遵循上下或左右布局）：

| 原则 | 含义 |
|---|---|
| 对比 | 完全不同的数据类型，选择截然不同的信息图示 |
| 重复 | 相同/相似数据，选用尽可能相同的展示 |
| 对齐 | 利用对齐保证信息图示之间的视觉联系 |
| 亲密性 | 相关数据项组织在一起，视觉上一体化 |

**总体要求**（1.2.1，适用于所有端）：

- 简洁明了、层次分明、重点突出，符合从左到右、从上到下的阅读习惯
- 全局一致性：同类组件统一交互模式
- 表达清晰、流程简洁、反馈及时准确
- 首页避免加载过多过大内容，保证加载顺畅，尽量减少新页面跳转
- 首页之外的页面保持"首页"按钮常驻，并有访问下级目录的引导
- 页面适配规则清晰，兼容主流浏览器，避免变形、组件缺失、文字错行错位；PC 端页面基本兼容主流移动浏览器
- 图片/附件/视频应有效可用、名称直观准确；宜采用 JPG、PNG、OFD、PDF、MP4 等主流格式
- 移动端符合移动设备交互方式，兼容主流屏幕尺寸与分辨率；**一般不使用弹出窗、漂浮窗**，确需使用时不多窗口且必须提供关闭按钮；支持通用移动终端操作系统
- 大屏端设计前先了解设备配置（类型、尺寸、分辨率、显卡、声卡、内存、网速、OS、浏览器）

## 2. 色彩系统

**总规则**：总色调不宜超过 **3 种**；绝大多数情况下以接近黑或白的中性色为背景，总体风格清新；文字颜色为黑 `#000000` 或白 `#FFFFFF`（也可按需在中性色/辅助色中选择，确保与背景对比充分）。

### 主色 Primary

| 令牌 | 色值 | 用途 |
|---|---|---|
| Primary-A | `#083DA6` | 常规用途：主按钮、图标色、文字链、局部背景 |
| Primary-B | `#CC3300` | 庆祝/纪念场景（按校方要求） |

> **A 与 B 不同时使用**（必须）。

### 辅助色/高亮色 Secondary / Accents（5 色）

| 令牌 | 色值 | 令牌 | 色值 |
|---|---|---|---|
| Orange | `#FF9900` | Purple | `#A80AF2` |
| Green | `#30F090` | Pink | `#E8316E` |
| Cyan | `#0ECAF0` | | |

用于交互界面控件元素，或作为主题色单独/组合应用于特定需求；应与主色形成恰当匹配。

### 中性色 Neutrals（10 级）

`#000000` `#292929` `#535353` `#7C7C7C` `#A6A6A6` `#CFCFCF` `#DFDFDF` `#E7E7E7` `#EFEFEF` `#F7F7F7`

用于背景、过渡色块等页面布局元素；**中性色作为背景时应避免使用中等灰度色值**（必须）。

### 系统通知 Feedback

| 语义 | 色值 | 用途 |
|---|---|---|
| Success 成功 | `#07F757` | 交互成功等正确性暗示 |
| Warning 警告 | `#FAE900` | 内容高亮显示 |
| Information 提醒 | `#002EE7` | 提醒通知 |
| Error 危险 | `#DB0000` | 错误提示 |

### 完整色阶

每个基色在规范色板中均有 10 级渐变（100 最深 → 950 最浅）。完整 CSS/JSON 令牌（含全部色阶）见 `tokens/tongji-tokens.css` 与 `tokens/tongji-tokens.json`。色阶由规范色板图采样还原，基值以规范文本为准。

## 3. 字体 Typography

**字体选择**：操作系统默认文字或跨 OS 兼容的开源字体（Roboto、Segoe UI、San Francisco、Noto Sans），全局保持一致。

| 平台 | 中文 | 英文 | 字重 |
|---|---|---|---|
| Windows | 微软雅黑 Microsoft YaHei | Segoe UI | Bold / Regular |
| macOS | 苹方简体 Ping Fang SC | Helvetica Neue | Semibold / Medium / Regular |
| iOS | 苹方简体 Ping Fang SC | San Francisco | — |
| Android | 系统内嵌中文字体 | Roboto 或系统内嵌字体 | — |

### PC 端字号表

| 层级 | 字号 | 行距 |
|---|---|---|
| H1 大标题 | 36px | 1.25 |
| H2 主标题 | 28px | 1.25 |
| H3 次标题 | 24px | 1.4 |
| H4 小标题 | 21px | 1.5 |
| Body 正文 | 16px | 1.6 |
| Body-sm 辅助文字 | 14px | 1.6 |
| Caption 说明 | 12px | 1.6 |

字号可根据实际需求微调。样例文字："同济大学一网通办 / Tongji Information"。

### 移动端字号

- 标题：16 / 18 / 20 / 24 / 32px
- 按钮文字：12 / 16 / 20px
- 正文：12 / 16 / 20px
- 提示信息：12px；标签：12px
- 行距一般为 **1.5 倍**；字号可按需设置阶梯

## 4. 界面布局

### PC 端（顶部 + 左侧导航 + 右侧内容）

| 区域 | 规格 |
|---|---|
| 头部区域 | 高度 **64px**；宽度随设备自由缩放，最小设备宽度 **1200px**；放置全局菜单入口、切换用户、个人中心 |
| 左侧导航 | 固定宽度 **240px**，文字超出 240px 时显示水平滚动条 |
| 内容区 | 距左侧导航 **24px**、距顶部页签 **16px**；宽度自适应，最小支持宽度 1200px |
| 间距单元 | 系统中最小距离单元 **8px**，允许 0.5 单元（**4px**）——所有间距取值应为 4/8/16/24… |

### 移动端（H5 / 小程序）

头部区域 + 内容区域 + **底部标签栏**；头部与内容按实际需求制定并在不同屏幕保持适配；底部标签栏用于子任务切换，**个数不超过 5 个**，高度一般 **32px**。

## 5. 组件速查

完整规格（含状态、场景、细则）见 references。

### PC 端

| 组件 | 关键规格 |
|---|---|
| 按钮 | 高 72/48/32px（大/中/小，默认 48）；圆角 9.6px；最小宽 80px，文字超宽时宽=文本宽+16×2px 内边距；文字与左右边框间距 16px；四态：默认/悬停/点击/灰态；悬停饱和度 -15%，点击 +15%，灰态不透明度 40% |
| 输入框 | 高 40/32/24px；默认/输入/禁用三态；右侧清空按钮；宽度固定；值居左、标题居右；数字框宜带增减按钮 |
| 单选框/复选 | 样式保持一致；默认/选中/灰态 |
| 选择器 | 建议 240×32、360×32；默认/下拉/灰态；选项 >10 项宜带搜索；支持部分选项禁用、可清空 |
| 树形组件 | 层级展开/折叠；内容多时顶部加输入框过滤 |
| 表格 | 行高 40px；列宽自适应（最小 1200px）；可变长文本居左、等长居中；可拖拽调宽；横滚时冻结重要字段 |
| 分页 | 首页禁用"上一页"、末页禁用"下一页"；可选每页行数；快速跳页；显示总页数；总页数 ≤5 显示全部页码 |
| 面包屑 | 默认/选中/悬停态；点击父级快速跳转 |
| 弹窗 | 页面正中；操作类固定 504×176px，其余宽 600/1000/1200px，高 320–600px；确认在右、取消/返回在左 |
| 消息提示 | 停留 **3 秒**后自动消失，可手动关闭；出现在屏幕四角；带图标（成功/警告/消息/错误） |
| 加载器 | 尺寸 18/36/64px；蒙版 `#FFFFFF` 70% 不透明度 |
| 穿梭框 | 表头复选框全选/全不选；一侧为空时穿梭按钮禁用 |
| 标记 Badge | 置于组件右上角，宜带数字（未读数） |
| 进度条 | 线性/环形 |
| 图表 | 推荐 ECharts 等开源库默认风格，配色与文字与系统一致 |

### 移动端

| 组件 | 关键规格 |
|---|---|
| 卡片 | 同一主题功能/组件/信息集中展示，便于快速识别关键信息 |
| 按钮 | 高 62/48/32px（大/中/小，默认 48）；圆角 9.6px；通栏或固定宽（如 120px）；一般用主色 A `#083DA6` |
| 图标按钮 | 图标 36×36px，长宽比 1:1，内容占满格约 80%；默认主色 A；含义与功能相符；**同一应用在不同平台保持一致** |
| 输入框 | 高约 80–100px；标题左对齐尽量不换行；必填有明确标识；右侧清空按钮；占位提示用中等灰；框外必要提示字号小于正文、可用 `#DB0000` |
| 标记 Badge | 颜色符合配色规范；置于组件四角之一，提醒类放右上角；宜带数字 |
| 弹窗 | 宽约屏宽 80%；提供关闭操作；分标题区/内容区；按钮用小按钮；确认在右、取消在左 |

## 6. 落地示例（PC 主按钮）

```html
<link rel="stylesheet" href="tokens/tongji-tokens.css"> <!-- 或拷贝变量到项目 */
<style>
  .tj-btn {
    height: var(--tj-btn-height-md);          /* 48px */
    min-width: var(--tj-btn-min-width);       /* 80px */
    padding: 0 var(--tj-btn-padding-x);       /* 左右 16px */
    border: none; border-radius: var(--tj-btn-radius); /* 9.6px */
    background: var(--tj-primary-a-500);      /* #083DA6 */
    color: var(--tj-text-inverse);
    font-family: var(--tj-font-pc-cn);
    font-size: var(--tj-font-size-body);      /* 16px */
    cursor: pointer;
  }
  .tj-btn:hover  { filter: saturate(0.85); }  /* 悬停：饱和度 -15% */
  .tj-btn:active { filter: saturate(1.15); }  /* 点击：饱和度 +15% */
  .tj-btn:disabled { opacity: var(--tj-btn-disabled-opacity); } /* 灰态 40% */
</style>
<button class="tj-btn">查询</button>
```
