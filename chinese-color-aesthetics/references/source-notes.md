# 两书来源与融合边界

本文件只记录用于构造 skill 的方法性摘要，不替代两本书，也不复制其正文。页码以扫描件中显示的书内页码为准；第二本书的前言、目录和正文存在页码重启/重复现象，必要时同时注明扫描顺序。

## 《观念之色：中国传统色彩研究》陈彦青

### 方法性依据

- **引言，书内页 002–010**：研究对象不是孤立的色块，而是中国传统色彩系统的观念、自然演化、目的性设计和色彩事件；要从史料、出土文物和古代图像理解色彩系统。作者还将色彩研究分为原理性、应用性、思想性和概论性等方向，提示研究与应用不可混为一谈。
- **第二章，书内页 025–032**：用从“浑然一色”到黑白、赤、黄等阶段说明色彩观念的形成；黑白关系涉及光线、明暗、昼夜、阴阳和关联思维。对本 skill 的启发是：先问颜色关系和观念结构，再问单色色相。
- **第七章，书内页 366–375**：讨论间色的身份转换、间色之间的进一步细化，以及间色在日常生活中的展开。正色与间色在不同层级、制度和场景中可能发生身份转换；间色也形成更细的色阶和社会生活中的具体色彩。
- **第八章，书内页 410–413**：总结中国传统色彩运用的核心是“观念”，色彩经过目的性建构成为独立的色彩系统；同时指出水墨可作为另一种精神色彩系统理解。对本 skill 的启发是：将观念命题和媒介特性置于色号之前。

### 不应过度推断

书中的五正色、五方、五行、正色/间色及其历史变化，不能压缩为跨朝代、跨地域、跨媒介的固定配色表。书中论证的是历史系统和身份变化，设计转译必须注明时期、对象和推断层级。

## 《中国传统色：故宫里的色彩美学》郭浩、李健明

### 方法性依据

- **前言，扫描顺序约第 006–012 页，书内页 003–009**：强调从汉字、古籍、器物、染色、故宫文物和中日传统色研究中整理色名；同一事物可能有多个色名，同一色名的色值也可能因材料和工艺而变。作者提出色名与色值的准确性需要专业、行业和社会共识，遇到偏差应持续修正。
- **前言，书内页 004–008**：色名可以从物象、典籍、雅乐、词牌或意象获得启发，但意象引申需要与正统色名区分；色值应“有理有据”，可从同色系深浅排序、文献考据和故宫文物辨色对照中推理。
- **目录，书内页 010–013**：正文以春、夏、秋、冬的节气和物候组织色彩，并设“故宫美”等延伸入口。这种结构适合作为叙事编排范式，不等于所有项目都要按二十四节气配色。
- **正文的春色示例，正文扫描顺序约第 020 页，页边标为 003**：每组以节气/物候标题、四格色块、色名和 CMYK/RGB 数值，再配一段短叙事。对本 skill 的启发是把“色名—意象—关系—数值—用途”放在同一个交付单元中。

### 不应过度推断

书中的 CMYK/RGB 是该书的现代编排与数字记录，不是古代色彩的唯一物理真值；扫描、显示器、印刷和材料都会造成差异。使用时标注“来源给定值”或“数字化近似”，不把书中收录数量或命名体系当作唯一、终结的中国色谱标准。

## 融合规则

两书可合并为以下工作链：

```text
陈彦青：观念/制度/历史事件/正色与间色关系
                         ↓
郭浩、李健明：节气/物候/色名故事/色块编排/CMYK-RGB记录
                         ↓
本 skill：证据卡 → 关系色谱 → 媒介转译 → 名值与可读性复核
```

融合后的流程是设计与研究方法，不声称代表全部中国色彩史，也不把两位作者的具体观点改写成无争议的学界共识。

## 实战转译边界

以下内容是本 skill 为了让哲学进入设计而做的应用化推导，不是两本书原文中的固定配方：

- “锚点/支持/过渡/强调/墨纸材质”是把色彩系统转成版面、品牌和产品角色的工作语言。
- 60/25/10/5 是平面设计的起始面积参考，不是传统色规则；应按内容、媒介和可读性调整。
- 把相生/相克转成协同/张力，是设计比喻，不是五行疗效或神秘因果。
- 把水墨转成留白、墨色层次、纸感和低饱和，是媒介转译；不能据此宣称某一方案就是古代水墨原貌。
- 色名故事可以帮助命名和沟通，但创意联想、作者推断和文献词源必须分栏标注。
