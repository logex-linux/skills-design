# NVIDIA Spark Hackathon 海报实例复盘

## 任务简报

- 交付：一张竖版活动概念海报。
- 主题：NVIDIA Spark Hackathon。
- 目标：让“AI / GPU / Agents”在缩略图尺寸下形成一个清楚、可记忆的视觉焦点。
- 限制：没有提供日期、场地、报名链接，因此不编造活动信息；不使用官方 NVIDIA Logo，不暗示官方发布关系。

## 两轮生成测试

### V1：基线

提示词建立了黑底、绿色中心能量核、严格网格和五段固定文案。结果的标题拼写正确，视觉主题成立，但中心光场过亮、线路过密，注意力被“效果”而不是“活动身份”吸走；底部元数据在缩略图中偏弱。

### V2：单变量迭代

只改四件互相关联的视觉层级变量：中心光晕缩小约 25%；能量场压到下半区；减少随机线路并加强网格节奏；稍微增强底部元数据。固定文案、色板、标题位置和概念性质不变。

结果：V2 的主标题、次标题和 supporting line 保持清晰，中心仍是唯一视觉焦点，但不再压过标题；画面从“泛科技壁纸”更接近可复用的活动视觉系统。

## 对 Skill 的优化

这次实例暴露出三个应写进 Skill 的条件规则：

1. **文字密集的生成海报必须有缩略图检查。** 逐字核对固定文案，并在小尺寸下检查标题、承诺句和元数据是否仍按层级可读。
2. **迭代要单变量。** 每轮只改一组有因果关系的视觉变量，保留文案、色板和构图不变，否则无法判断改进来自哪里。
3. **品牌主题和官方身份分开。** 没有官方素材或活动信息时，输出应明确为概念海报，不编造日期、场地、链接、赞助方或官方 Logo。
